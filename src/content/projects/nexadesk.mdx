<Chapter title="What it is">

NexaDesk is a desktop assistant for Linux and Windows. It has two faces over the same assistant: a chat window with saved history, and an avatar mode where a pixel-art character shows whether it is idle, thinking, working, speaking or has hit an error. The interface comes in dark and light themes, in English and Turkish.

<Chapter title="Screen control and permissions">

The assistant can take screenshots, read text with on-device OCR, use the mouse and keyboard, and list or focus windows. The control server is embedded in the app, listens only on the local machine and requires a token that changes on each start.

According to the project’s documentation, mouse, keyboard, OCR and window control wait for you to allow or deny them, and each tool’s permission can be changed in Settings.

On Linux, keyboard and mouse tools need access to `/dev/uinput` or an X11 session.

</Chapter>

<Chapter title="Models and data">

Ollama runs models locally. Groq, NVIDIA, Google and other OpenAI-compatible services can be configured instead. API keys are kept in a local secrets file that is excluded from the repository and packages, and chat history is kept in a local SQLite database.

“Local-first” has a boundary: with a cloud provider, your messages, screenshots and recognized text can be sent to that provider. OCR itself runs on your device.

</Chapter>
